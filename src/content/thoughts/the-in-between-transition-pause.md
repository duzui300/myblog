the in-between time:  
from when a sound is made  
to when it returns as an echo  

no one knows  
if it was heard  
when it was heard  
when it would be heard  
if ever at all  

but it continues  
on and on and on  
maybe thousand years  
someone's memory  
tale legend poem dream
